# 视频时序库

## 把运镜写成可观察变化

| 用户想要 | 术语 | 可用描述 |
| --- | --- | --- |
| 镜头跟着人平行走 | 侧向横移跟拍 | 相机与主体并行向右，保持正侧面和距离，近景比远景掠过更快 |
| 站在原地转头看 | 横摇 | 相机位置固定，朝右水平转动，扫到指定目标后停稳 |
| 镜头向人靠过去 | 推进 | 相机实际向前移，取景从中景收至胸上，前景退出并产生视差 |
| 原地把人看大 | 变焦 | 相机留在原位，视角收窄，主体在画面中变大 |
| 看到人物的另一侧 | 环绕 | 相机绕站定主体沿弧线移动，背景视角随相机改变 |
| 跟着跑但画面仍能看清 | 受控手持 | 相机随步伐轻微起伏，保持主体脸或关键动作可辨 |
| 让场景像自然经过 | 前景遮挡转场 | 门框、战旗或烟团贴近镜头，覆盖画面后揭露下一场，保留运动方向和主体锚点 |
| 看清最关键的一下 | 局部慢动作 | 动作正常起步，接触前后短暂减速，随后恢复常速 |

## 组织动作 音频和参考

- 单镜头先固定主体特征与主运镜，每个时间段用一个主动作起步。写清主体与相机各自的方向、接触物及结束位置。镜头连续时，一个时间段对应一个事件，分段本身不意味着剪切。
- 多镜头写清共同主体与必须保持的服装、道具、方向和声轨，再标出每镜景别与切换触发。追求严谨连续时优先使用合适的参考素材、重复同一身份锚点和匹配段尾段首的视线与动作。参考图若是首帧，明确「从该画面开始」。若只供造型参考，明确「仅借用外观」。
- 一份参考承担一个主要角色，例如「图 1 只定角色脸与服装，视频 1 只定镜头轨迹，音频 1 只定节拍」。先核对附件是否实际存在，避免把文件名或样例中的素材编号自动当成已上传的参考。需要用户上传时，把动作写在提示词外。
- 保留声源及其触发点，例如「马蹄落在水坑时同步响起溅水声」。用户要求无配乐时可保留雨声和脚步声。完全静音优先用平台音频设置。逐字对白标发声人和时间段，保留语言。只口播时把无字幕单独写清。
- 检查时间段从 0 开始且连续覆盖总长。版本不明时保留目标时长和分段方案，提示用户在对应入口核对可选时长。对长镜头多角色、高速接触、复杂物理和多次转场，先保护必需动作，按需减少可选背景事件。若用户允许拆分，可用遮挡、同一构图或末帧作为接点，再剪辑与配音。
