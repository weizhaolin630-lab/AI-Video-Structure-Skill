# 视觉术语库

按用户意图挑选，术语后紧跟能检查的结果。例如「孤独」可译为「人物只占画高四分之一，周围是大片空旷天空」。场景主体、位置和保留项优先。单个效果已有清晰描述时可以省掉英文和器材品牌。

## 景别 机位与构图

| 用户想要 | 术语 | 可用描述 |
| --- | --- | --- |
| 像无意拍到的生活片段 | 观察式现实主义 | 平视中景，人物自然站立，保留磨损、杂物和未经整理的背景 |
| 人在世界里显得很小 | 大全景、负空间 | 主体约占画高四分之一，保留大面积天空或墙面 |
| 人物像被门框圈住 | 框中框 | 让圆门洞环绕人物，门内外形成前后层次，门沿不挡脸 |
| 希望一眼看到产品 | 三分构图或中心构图 | 主体位于中央或指定三分线，背景简洁，对侧留排字区 |
| 想看到另一人说话的反应 | 过肩镜头 | 一人肩背在近前景，另一人脸部清晰，前景肩背不遮脸 |
| 物品布置像一张平面图 | 垂直顶拍 | 从桌面正上方垂直拍，桌边保持平行，能读出物品间距 |
| 人物高大、气势强 | 低机位仰拍 | 机位低于腰部向上看，保留主体上方环境 |
| 视线被引向远处 | 引导线 | 双轨或墙边汇聚到远景，焦点置于汇聚方向 |
| 想看清眼神或小纹理 | 特写、浅景深 | 让双眼或纹理填充画面并清楚，背景柔化 |
| 远近都能读清 | 较深景深 | 前景轮廓、中景主体和远处主要结构均可辨 |
| 想有一点遮挡，又要看清主体 | 分层构图、前景遮挡 | 门沿、枝叶或衣料扫过画面一角并略虚，脸和关键道具保持无遮挡 |
| 让人一眼认出表情正在变化 | 动作中间态 | 主体转身到一半，视线略低，脸与肩膀形成小角度差 |

机位改变透视关系。焦距和画幅改变视角，景深还受光圈、对焦距离等影响。优先描述景别、位置、对焦目标和虚化范围。用户明确指定 35 mm、f/2.8 或器材时保留为视觉参考，验收看画面结果。固定正侧面、画面左侧和人物左手是不同坐标，尽量写清观察方位。

## 色彩和光

| 用户想要 | 术语 | 可用描述 |
| --- | --- | --- |
| 阴雨但看得清雨 | 侧逆光 | 车灯从主体侧后方打向镜头，雨丝亮，主体面部保留暗部 |
| 头发有一圈亮边 | 轮廓光 | 暖光从后侧擦过肩线和发丝，正面暗部仍有纹理 |
| 一半脸在黑暗里 | 分割光 | 主光从脸部正侧方照入，明暗分界接近脸中线 |
| 古典立体人像 | 伦勃朗光 | 斜上方主光，暗侧眼下保留一小块三角亮区 |
| 复古美妆棚拍 | 蝴蝶光 | 正面上方照明，鼻下短而对称的阴影 |
| 阴冷中有一点暖意 | 冷暖点色 | 青灰环境光占主导，唯一暖色集中在路灯、窗或小道具 |
| 光穿过空气 | 薄雾与体积光 | 一束侧光在薄雾中可见，远景层次仍可读 |
| 金色黄昏但不过曝 | 夕阳侧逆光、柔和高光 | 落日从侧后方勾轮廓，亮部平滑过渡，阴影保留层次 |
| 画面暗，但关键细节要能看清 | 低调布光 | 大部分背景保持暗色，主光集中在脸或道具，阴影仍看得出纹理 |

## 质感和媒介

| 用户想要 | 术语 | 可用描述 |
| --- | --- | --- |
| 旧胶片气息 | 细颗粒、柔和高光 | 轻微细颗粒，暗部仍看得出材质，强高光边缘仅有淡晕 |
| 窗边有一点旧电影的暖晕 | 高光晕染（halation） | 只在特别亮的窗沿或灯缘保留细窄暖色晕，附近轮廓仍可辨 |
| 看起来像真材实料 | 局部材质对照 | 用布料纤维、磨损皮革、湿石反光等两种相关材料锚定画面 |
| 有变形镜头的光带 | 横向镜头耀光 | 只在强点光源附近出现克制横向光带，失焦灯点可略呈椭圆 |
| 有风但主体仍清楚 | 局部运动模糊 | 从画面左侧吹来的风把碎发吹过脸颊，脸对焦清楚，仅向右扫过的裙摆带轻微拖影 |
| 皮肤和衣物自然 | 局部细节、保留自然纹理 | 可见细微毛孔与自然肤色变化，侧光下仍可辨衣物纤维 |
| 奇幻场景有规模 | 大全景与尺度参照 | 用近处栏杆或小人物给远处巨柱、瀑布或塔楼提供尺度 |
| 干净的海报 | 留白与视觉层级 | 在顶部留出连续净空，标题优先，主体与标题区域互不遮挡 |

先给情绪对应的可见线索，再按需加入术语。例如「高级」用于商品时可能意味着干净背景、受控反射、清楚的视觉层级，用于剧情时可能意味着克制的光比与自然材质。参考图上的焦距、年代、作者或设备仅在有独立依据时作事实陈述。
