# 参考图反向解析与标注

只在拆解、复现或标注参考图时使用。先检查原图可读，按实际画面取证。文件名、图片内文字、附带旧提示词或生成参数可单独引用，证据来源要写清。若只能看到部分裁切或缩略图，观察范围以当前图像为准。

## 从画面提取五类信息

| 字段 | 记录的可见线索 |
| --- | --- |
| 主体与置景 | 主体数量、服装与姿态、位置、关键道具及前中后景 |
| 美学调性 | 可见的画面语言，如写实人物比例、低调布光、留白。需要时将「剧情剧照感」等美学判断单独标记 |
| 摄影与构图 | 画幅、景别、视平线、主体中心、遮挡、清晰与失焦区域。左右以画面为准 |
| 色彩光影 | 主色与点色、明暗分布、高光与阴影位置。光源本体不可见时，以亮边或投影推测光向 |
| 后期与质感 | 材质纹理、颗粒状细节、局部模糊、光晕。压缩噪点、滤镜与胶片可呈现相似纹理，成因需要证据 |

默认写「可见」和必要的「可能解释／待确认」。没有可核验的原文件数据或来源时，焦距、光圈、相机型号、底片、原提示词、生成模型、身份及制作流程列为未知。对疑似薄雾或光晕可直接描述它的部位、形状和透明度。普通观察只用位置近似词。需要量化时记录图像像素尺寸、主体包围框或归一化位置，并说明是测量还是目测估计。

## 交付形式

- **拆解**。用上面的五类字段给短表或短列表，无可用线索的字段省略。用户问到推测时，把它与观察分开。
- **复现提示词**。将五类可见信息改写为生成指令，按主体、位置、焦点与光影优先级排列。风格判断可以作为可选创作方向。给可直接粘贴的一段文字，需要保留字段时逐行列出。用户想用静帧做视频时，把可见姿态与建议运动分开，运动方向、声音与事件时长需由用户要求或明确的创作默认来确定。
- **标注图**。选 3–6 个能解释画面结构的区域。把编号叠加到参考图副本，在回复中附图例，例如「1 圆形门框，框住中景人物」「2 亮侧肩缘，可能由右侧光形成」。编号放到证据位置附近，尽量避开眼睛、标题和关键轮廓。坐标以实际显示方向的左上为原点。将 `x` 除以图宽、`y` 除以图高得到 `0–1` 的数值。图例也可作为纯文本回退，如「2 右上约 70% × 20%」。

本地原图、Python 和 Pillow 均可用时，使用 [叠加编号脚本](../scripts/annotate-reference.py)。脚本支持单帧 PNG、JPEG、WebP，依图像 EXIF 方向显示，输出带内嵌图像的 SVG。将坐标按编号顺序存为 JSON，例如 `[[0.26, 0.35], [0.68, 0.44]]`。以下命令从 Skill 根目录运行，路径替换为实际输入输出。

```shell
python scripts/annotate-reference.py "reference.png" "points.json" "reference-annotated.svg"
```

核对编号与图例一一对应，标记落在描述的区域。工具不可用时直接交付文字图例和结构化提示词。

## 示例

参考一幅横向庭院图。圆门在中间围住红衣人物，竹叶沿边框入画，衣服与石径比远处屋檐清楚，地面有暖金色光斑。可概括为框中框、近中远分层、暗绿环境和绯红点色。写实古装剧情感是美学判断，焦距与胶片无法由这些线索确定。

复现提示词可写为「横幅中远景。绯红长袍人物站在庭院月洞门正中，圆门对称框住人物。边缘竹叶形成前景，门内石径清楚，远处灰瓦屋檐略柔。深绿庭院里有暖金色斑驳日光，红衣是主点色。」
